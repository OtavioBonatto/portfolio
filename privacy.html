Política de Privacidade — Sentinel Crypto

Última atualização: [DATA]

1. Introdução

O Sentinel Crypto é um aplicativo de monitoramento de mercado de criptomoedas. Esta política explica, de forma direta, como tratamos dados.

2. Dados que coletamos

Nenhum. O aplicativo não solicita cadastro, não requer login e não coleta, armazena ou transmite dados pessoais para servidores do desenvolvedor.

3. Dados armazenados no seu dispositivo

As preferências de uso (par monitorado, timeframes, indicadores e idioma) são salvas localmente no seu dispositivo, usando o armazenamento padrão do sistema operacional. Esses dados nunca saem do aparelho e podem ser apagados desinstalando o aplicativo.

4. Dados de terceiros

O aplicativo consulta dados públicos de mercado (cotações e candles) diretamente da API pública da Binance. Consulte a política da Binance para saber como eles tratam requisições. O aplicativo não envia nenhum dado pessoal a eles.

5. Permissões

Internet: para consultar cotações. Notificações: para exibir alertas de sinais configurados por você.

6. Menores de idade

O aplicativo não é direcionado a menores de 13 anos.

7. Alterações

Alterações nesta política serão publicadas nesta mesma página.
